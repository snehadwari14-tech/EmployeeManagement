Employee Management Portal

This project is an Employee Management Portal developed to manage employee information.

Technologies Used

- HTML
- Python
- Flask

Features

- Employee Registration
- Employee Search
- Employee Management

Project Description

The Employee Management Portal helps manage employee records efficiently. It provides basic functionality for employee registration and searching.

## Installation Guide

1. Install Python.
2. Install Flask using pip.
3. Run the application using python app.py.
